# data/

This folder holds the raw inputs to the drought-briefing pipeline. Everything
here is either a small, versioned master-data file, or an offline fallback
fixture — the large per-run datasets (`data/raw/`, `data/processed/`) are
pipeline build artifacts and are gitignored, not stored here.

## Master data

| File | Contents |
|---|---|
| `kantone_warnregionen.json` | Canton <-> warning-region master data (BFS canton numbers, map center coordinates). Consumed by `config/settings.py`. |
| `station_region_mapping.json` | `hydro_station_id -> drought_region_id` mapping. Generated by `scripts/extract_station_mappings.py` — see below. |

## Station mapping (`stations.pdf`)

`stations.pdf` is BAFU's published station list. `scripts/extract_station_mappings.py`
reads it together with the `reference` fixture zip's `regions.csv`, matches
each station to a region by name, and writes `data/station_region_mapping.json`.
Re-run it whenever BAFU publishes an updated station list PDF (replace
`stations.pdf` with the new version first):

```
uv run python scripts/extract_station_mappings.py
```

## Fixtures (`data/fixtures/`)

Offline fallback data, used when the corresponding live API/endpoint or
`data/raw/` (see `scripts/download.py`) is unavailable (see each client's
docstring / `src/data/fixture_loader.py`'s module docstring for the exact
fallback trigger):

| File | Refreshed by | Falls back for |
|---|---|---|
| `fixtures/warnkarte_fixture.json` | `scripts/refresh_warnkarte_fixture.py` | `src/data/warnkarte_client.py` (BAFU Warnkarte API) |
| `fixtures/vhi_fixture.csv` | `scripts/refresh_vhi_fixture.py` | `src/data/vhi_client.py` (SwissEO VHI endpoint) |
| `fixtures/trockenheitsdaten-numerisch_current__*.csv.zip` | *(no refresh script yet)* | `src/data/fixture_loader.py` — current period + forecast, used when `data/raw/current.zip` is absent |
| `fixtures/trockenheitsdaten-numerisch_historic__*.csv.zip` | *(no refresh script yet)* | `src/data/fixture_loader.py` — long-term historic comparison (from 1991), used when `data/raw/historic.zip` is absent |
| `fixtures/trockenheitsdaten-numerisch_reference__*.csv.zip` | *(no refresh script yet)* | `src/data/fixture_loader.py` — per-station/day-of-year reference thresholds (`threshold1`, `q347`) and region master data (`regions.csv`), used when `data/raw/reference.zip` is absent |

The three `.csv.zip` fixtures don't yet have a refresh script analogous to
`refresh_warnkarte_fixture.py`/`refresh_vhi_fixture.py` — a reasonable future
addition, not done here.
