# data/

This folder holds the raw inputs to the drought-briefing pipeline. Everything
here is either a small, versioned master-data file, or an offline fallback
fixture — the large per-run datasets (`data/raw/`, `data/processed/`) are
pipeline build artifacts and are gitignored, not stored here.

## Production data

| File | Contents |
|---|---|
| `trockenheitsdaten-numerisch_current__*.csv.zip` | Latest BAFU drought indicator data (current period) |
| `trockenheitsdaten-numerisch_historic__*.csv.zip` | Long-term historic comparison data (from 1991) |
| `trockenheitsdaten-numerisch_reference__*.csv.zip` | Per-station/day-of-year reference thresholds (`threshold1`, `q347`) and region master data (`regions.csv`) |
| `kantone_warnregionen.json` | Canton <-> warning-region master data (BFS canton numbers, map center coordinates). Consumed by `config/settings.py`. |
| `station_region_mapping.json` | `hydro_station_id -> drought_region_id` mapping. Generated by `scripts/extract_station_mappings.py` — see below. |

These three `.csv.zip` files are real production downloads, not test
fixtures, despite living in the same folder as the fixtures below.

## Station mapping (`stations.pdf`)

`stations.pdf` is BAFU's published station list. `scripts/extract_station_mappings.py`
reads it together with the `reference` zip's `regions.csv`, matches each station
to a region by name, and writes `data/station_region_mapping.json`. Re-run it
whenever BAFU publishes an updated station list PDF (replace `stations.pdf`
with the new version first):

```
uv run python scripts/extract_station_mappings.py
```

## Fixtures (`data/fixtures/`)

Offline fallback data, used when the corresponding live API/endpoint is
unreachable (see each client's docstring for the exact fallback trigger):

| File | Refreshed by | Falls back for |
|---|---|---|
| `fixtures/warnkarte_fixture.json` | `scripts/refresh_warnkarte_fixture.py` | `src/data/warnkarte_client.py` (BAFU Warnkarte API) |
| `fixtures/vhi_fixture.csv` | `scripts/refresh_vhi_fixture.py` | `src/data/vhi_client.py` (SwissEO VHI endpoint) |
